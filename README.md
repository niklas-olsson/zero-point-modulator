# Zero Point Modulator

Zero Point Modulator (ZPM) manages repository enrollment and operator-selected worker capacity. OpenJules supplies executable workers and bounded child agents; Keystone Polyphony supplies collaboration and protected task authority.

The implementation is being developed through these work packages:

- [Repository enrollment and runtime bindings](https://github.com/niklas-olsson/zero-point-modulator/issues/1)
- [Worker capacity reconciliation and recovery](https://github.com/niklas-olsson/zero-point-modulator/issues/2)
- [Reproducible installation and complete workflow verification](https://github.com/niklas-olsson/zero-point-modulator/issues/3)

This initial repository baseline establishes the project intent. Installation and runtime capabilities are tracked in the linked work packages.
